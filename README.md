# HR Pulse

HR, attendance (with location), payroll, teacher pay and SIG commission management.
Next.js 15 · TypeScript · Tailwind CSS · clean architecture · demo data included.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000 and pick a demo account (Super Admin / Admin / Employee).

Full details, backend endpoints and production steps: [docs/DOCUMENTATION.md](docs/DOCUMENTATION.md)
